# 千问对话流 · 高舱智能推荐系统

> **Flight Cabin Intelligence Skill** — 基于航司数据 × 对话理解 × H5 自动生成的商务舱推荐能力

## 项目概述

本项目是飞猪 OTA 平台与通义千问 AI 对话流深度结合的**高舱（商务舱）智能推荐系统**，核心目标是将航司的前舱体验从"静态页面展示"升级为"可自动生成的销售能力"。

当用户在对话流中表达出行意图时（如"晚上飞香港，有点累，想舒服一点"），系统自动完成：

1. **意图识别** — 基于关键词评分模型判断商务舱推荐倾向
2. **数据拼装** — 从结构化航司数据库拉取真实的座椅、餐食、设施信息
3. **页面生成** — 输出包含完整高舱体验信息的沉浸式 H5 页面

区别于普通大模型输出的泛化内容，本系统所有展示信息均来自**经过校验的航司级数据**，禁止 LLM 编造舱位参数与媒体链接。


## 核心能力

### 1. 商务舱推荐判断（倾向分模型）

基于用户对话中的关键词进行**无 LLM 的评分计算**，决定是否触发商务舱推荐：

| 类别 | 示例关键词 | 分值 |
|------|-----------|------|
| 舒适需求 | 舒服、躺平、不想太累 | +25 |
| 特殊人群 | 老人、父母、带娃 | +25 |
| 红眼疲劳 | 红眼、凌晨、长途 | +20 |
| 商务场景 | 出差、报销、见客户 | +15 |
| 预算敏感 | 最便宜、学生、穷游 | -35 |

倾向分 B >= 20 时优先展示商务舱推荐模块；B <= -20 时隐藏或强降级。

### 2. 航司数据库（CabinKB）

自动爬取并结构化的航司真实数据，当前已覆盖：

- **国泰航空（CX）**：6 种机型、13 种配置版本
- 数据维度：座椅布局、腿距/椅宽/可调角度、用户评分、配套设施、机上餐食、座位图
- 数据来源：seatmaps.com、航司官网

### 3. H5 沉浸式体验页

自动生成的高保真 H5 页面，包含：

- 对话流式交互（千问 AI 对话 + 机票推荐卡片）
- 商务舱 Upsell 模块（手风琴展开、事实网格、口碑证据）
- 国泰航空品牌沉浸式体验（Hero 视频、座椅大图、餐食展示）
- 移动端适配（375px 基准，响应式 320-430px）

### 4. 编排层原型（Orchestrator）

对话推荐的后端编排服务原型，实现：

- 并行检索经济舱 + 商务舱报价
- CabinKB 机型/座椅知识拉取
- 流式协议（SSE）支持文本增量 + 结构化 Block
- Schema 校验与图片域名白名单

## 技术栈

| 层面 | 技术 |
|------|------|
| H5 页面 | 原生 HTML/CSS/JS，CSS Variables 承载 Design Token |
| 编排服务 | Node.js，SSE 流式协议 |
| 数据校验 | JSON Schema（AJV） |
| 设计工具 | Figma + Figma MCP（自动化读写画布） |
| AI 对话 | 通义千问（Qwen），LLM 仅负责短文案生成 |
| 数据采集 | flight-data-collector（Headless Browser） |

## 商业价值

**对用户**：在对话流中获得基于真实数据的商务舱体验展示，提升决策信心

**对航司**：在 OTA 平台获得可规模化的数字销售窗口，支持前舱体验采购合作

**对平台**：形成可商业化的高舱展示能力，支撑航司营销合作与高客单价转化

## 查看效果

### 对外分享链接（GitHub Pages）

首次开启后，你可以把这个链接发给任何人直接访问：

- 首页（ASCII 入口）：`https://<GitHub用户名>.github.io/<仓库名>/`
- 直达页面：`https://<GitHub用户名>.github.io/<仓库名>/Qwen-%E5%AF%B9%E8%AF%9D%E6%B5%81.html`

### 一次性启用步骤

1. 把仓库推送到 GitHub（`main` 分支）。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Source: GitHub Actions**。
4. 确认仓库里存在工作流：`.github/workflows/deploy-qwen-dialog.yml`。
5. 触发一次 push，等待 Actions 里的 `Deploy Qwen Dialog H5` 执行成功。

### 日常同步更新流程

后续你只需要继续改原文件：

- `2 H5效果/Qwen-对话流.html`
- 以及它依赖的资源（如 `2 H5效果/assets/**`）

然后执行：

```bash
git add .
git commit -m "update qwen dialog h5"
git push
```

每次 `git push` 后，GitHub Pages 会自动重新发布，分享链接内容同步更新。

### 说明

- 发布站点根目录来自 `2 H5效果/`，相对路径资源会按原结构一起发布。
- 工作流会自动生成 `index.html`，用于无中文文件名的入口跳转，便于分享。
