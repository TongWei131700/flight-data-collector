核心判定规则 · 倾向分
倾向分 B 算法
舒适意图
舒服舒适躺平宽敞睡得好
命中任意一词，仅计一次
+25
特殊人群
老人父母长辈带娃孕妇
命中任意一词，仅计一次
+25
红眼疲劳
红眼夜班凌晨长途国际
命中任意一词，仅计一次
+20
商务场景
出差报销见客户会议
「出差+报销」同属一类，合计仅 +15
+15
价格敏感
最便宜低价学生预算省钱穷游
整轮仅计一次，不重复惩罚
−35
📐 排序公式
B = clamp(B, −40, 80)
R = R₀ + w × B
R₀ = 业务基础分（价格/时长/直飞/库存）
w ∈ [0.3, 0.6]，与 R₀ 量级同比缩放
⚠️ 计分注意事项
①同类多词命中，不重复加分，每类最多 +1 次
②「出差」+「报销」同属商务场景，合计仅 +15，不是 +30
③减分整轮计一次，多轮对话不重复惩罚
④可选叠加上一轮一句，增强上下文感知
⑤B 值截断在 [−40, 80]，防止极端值影响排序
核心判定规则 · 第三槽
第三槽 曝光策略
B ≥ 20
高意向
优先展示商务舱
可放宽价差阈值，主动推荐第三槽；排序分 R 显著提升
🏁
−20 < B < 20
中性
走默认价差策略
按正常价差规则决定是否展示，不主动放宽也不降级
🔵
B ≤ −20
价格敏感
隐藏或强降级
第三槽不展示或降至最低权重，避免强推引发反感
🔴
💡 计算示例
「红眼航班，带老人出行」
红眼 +20 + 老人 +25 = B = 45
→ 第三槽优先展示，价差阈值放宽
「出差，帮我找最便宜的」
出差 +15 + 最便宜 −35 = B = −20
→ 恰好触发阈值，第三槽隐藏或强降级
「帮我订去北京的票」
无关键词 = B = 0
→ 走默认价差策略，正常判断
📌 前提条件
以上策略均在商务舱有库存时生效。
无库存时，无论 B 值多高，第三槽均不展示。
价差阈值由产品策略配置，非硬编码。
核心判定规则 · 禁推
商务舱 禁推规则
以下任一条件成立，商务舱推荐模块整体不展示，B 分不参与判断
⏱
短航程禁推
航段飞行时长 < 2 小时，商务舱推荐模块整体不展示。
短途航班舒适差异不显著，强推易引发用户反感。
🚫 整体不展示
🚫
无库存禁推
FlightAPI 返回商务舱 无可售座位，不展示可订卡片。
可显示「售罄 / 无票」态，但不出现可点击的订购按钮。
🚫 不展示可订卡片
💰
价格敏感强降级
用户输入含价格敏感词，B 分计算后 B ≤ −20，第三槽隐藏或强降级。
不受航程长短影响，单独触发。
🚫 隐藏或强降级
⚠️ 规则优先级
1
无库存 — 最高优先，无论 B 值多高均不展示
2
短航程 — 航段 < 2h，整体模块不渲染
3
价格敏感 — B ≤ −20，第三槽降级
💡 判断流程
① 库存检查 无库存 → 直接禁推，流程终止
② 航程检查 < 2h → 整体不渲染，流程终止
③ B 分策略 计算 B 值，决定第三槽曝光等级
