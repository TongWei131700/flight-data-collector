# Assets 目录说明

本目录存放项目相关的静态资源文件。

## 子目录结构

| 目录 | 说明 |
|------|------|
| `demos/` | H5 效果演示页面和代码 |
| `previews/` | 预览图片和视频文件 |

## 重要文件

### previews/H5页面.mp4
- **类型**: 视频文件
- **说明**: 项目的最终效果演示视频
- **用途**: 展示 H5 页面的完整交互效果

### previews/阿联酋航空爬取 - 02.mp4
- **类型**: 视频文件
- **说明**: Skill 抓取数据示例视频
- **用途**: 展示使用本 Skill 抓取阿联酋航空数据的完整过程，是第一个成功运行的 Skill 抓取数据示例

## 命名规范

- 图片文件：使用小写英文，单词间用连字符 `-` 连接
- 视频文件：使用中文或英文描述性名称
- 避免使用特殊字符和空格
