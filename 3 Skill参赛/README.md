# 作品：H5 高舱升级全链路 Demo Skill

## 作品名称 + 一句话说明

### 默认作品名（推荐）
**《1 分钟生成一个可交互的“高舱升级全链路”H5 Demo》**  
一句话：**在千问对话流里，用“LLM 只负责短话术 + 航旅行业独有事实数据（机型/座椅/评分/图片/报价与库存）只从业务服务下发”的方式，演示一个可控、低幻觉的商务舱推荐与购买全链路。**

### 备选命名（可替换）
- **《对话流高舱 Upsell H5 生成器》**：把对话式推荐体验做成可演示的 H5
- **《高舱购买全链路交互样机》**：面向产品/设计/前端的一键可视化样机

## 适用人群
- **PM/运营**：快速拿到可演示的“全链路 + 对话流”样机，用于评审/对齐/汇报
- **设计师**：验证信息层级、关键交互与节奏（feed streaming、对比表、CTA）
- **前端**：基于现成结构快速二开（数据注入、组件替换、接入真实接口）
- **AI Coding Agent 使用者**：把固定的演示资产整理成可复用工作流

## 使用示例（输入 / 输出）

本参赛版目标是 **1-2 分钟内出结果**，所以默认走“直接打开现成 H5”路径；必要时用本地静态服务器打开（解决部分浏览器对本地文件的限制）。

### 示例 1：最快路径（零配置）

**输入（命令）**

```bash
open "Qwen/H5/high-cabin-fullchain.html"
```

**输出（结果）**
- 打开一个可交互 H5，包含 5 步流程：**推荐 → 对比 → 填单 → 确认 → 完成**
- 关键体验点：
  - 对话流 feed 分步流式渲染（“飞猪顾问/我”对话节奏）
  - 商务舱/经济舱对比表（可切 tab）
  - 填单校验（协议勾选 + 手机号校验）
  - 底部 CTA 随步骤变更文案与可用性

### 示例 2：可配置路径（输入 = 改一份 JSON，输出 = 生成的新 HTML）

**输入（文件）**
- 模板文件：`Qwen/H5/high-cabin-fullchain.html`
- 你要改的“输入数据”主要在页面内这两块（搜索即可定位）：
  - `compareData`：对比表数据（biz/eco）
  - `streamFeedData`：五步对话流数据（1~5）

**输入（你修改的内容示例）**
- 把路线、价格、标题、副标题、chips、evidence 文案换成你的案例
- 把 `streamFeedData` 的对话换成你的业务脚本（保持 `{ role, text }` 结构）

**输出（文件）**
- 保存成新文件，例如：`dist/demo.html`
- 用浏览器打开：`open dist/demo.html`

> 说明：参赛版只要求“输入输出示例”可对照理解，因此这里把“输入”定义为你可控的数据与文案，“输出”定义为可打开的 H5 成品文件。
