第 4 页
子Skill1 - 航司数据爬虫（Flight Data Collector）
目标：把座椅/餐食/设施/机型配置等分散信息抽取成可验证的结构化事实库。 输入：官网与产品页、机型配置说明、图片素材 输出：airline + aircraft（+variant） cabin_facts（字段口统一，可回溯） 质量控制：缺失字段提示、图片白名单与内容哈希
第 5 页
子Skill2 - 推荐规则判断

商务舱倾向分 B（关键词规则，无 LLM）

B = clamp(B, -40, 80)
R = R0 + w × B（w ∈ [0.3, 0.6]）
模块 规则（简化）
加分 舒适 +25；人群 +25；红眼疲劳 +20；商务场景 +15（每类命中任意词只计一次）
减分 预算敏感整轮只计一次：最便宜/省钱/特价/穷游… → B -= 35
第三槽 B ≥ 20：优先展示且可放宽价差阈值；-20 < B < 20：默认；B ≤ -20：隐藏或强降级
